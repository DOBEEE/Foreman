# 本地知识库

本目录是答疑助手（assistant agent）的检索语料，作为**只读根**挂给 assistant（它自己的工作目录是隔离的 `/tmp/foreman/assistant`，并非本目录）。assistant 用 Glob/Grep/Read 检索后作答并标注来源。

目录位置由 `KNOWLEDGE_DIR` 环境变量决定，默认 `<服务安装根>/knowledge`（即本目录）。

## 使用约定

- 按主题建子目录（如 `foreman/`、`frontend/`），文档用 markdown
- **每篇文档首行写一级标题 `# xxx`** —— 它会被自动抽取成知识库索引内联进 assistant 的系统提示词，是模型判断"该读哪篇"的唯一依据，标题含糊会直接导致检索跑偏
- 一篇文档聚焦一个主题，超大文档建议拆分（检索命中更准）
- 小标题写清关键词，便于 Grep 命中
- 只放文本类文档（md / txt），不放二进制文件
- **不要放凭据**（密钥 / token / 证书）：assistant 的回复会直接发到钉钉群；`.env`、`*.key` 等命中敏感名单的文件会被钩子拦截，但不要依赖这层兜底
- 文档更新即生效，无需重启服务（索引每次运行重新扫描）
